# Guandu Dispatch v0.6 Implementation Plan

> **For agentic workers:** execute inline with test-first changes and verification after each subsystem.

**Goal:** Upgrade the v0.6 vertical slice into a coherent Three-Kingdoms military-investigation experience with persistent scene progress, tactile evidence interactions, differentiated interrogation feedback, and a production-ready visual system.

**Architecture:** Keep the existing React/Vite game/domain split, extend GameState with persisted presentation progress, and make scene components read/write that state instead of owning unrecoverable local navigation. Replace placeholder CSS-geometry characters and generic cards with reusable scene art/UI primitives, while preserving the existing rules/content model and widening the vertical-slice interactions rather than rewriting the full game.

**Tech Stack:** React 19, TypeScript 6, Vite 8, Vitest, Testing Library, CSS.

**Spec:** user-approved C direction in conversation: Three-Kingdoms historical atmosphere + modern game UI readability, investigation-first interactions, lightweight 2.5D/CSS motion, persistent progression.

## Global Constraints
- Keep the project runnable as a browser game and package the complete source as `Guandu-Dispatch-v0.6.zip`.
- Preserve the existing case content and later IntelDesk implementation; upgrade the v0.6 vertical slice without deleting later systems.
- Prioritize readable interaction over decorative historical ornament.
- No answer-revealing highlight before the player actively records a clue.
- Scene progression must survive reloads through the persisted GameState.

---

### Task 1: Persist v0.6 presentation progress
- Add version-3 presentation state and v1/v2 migrations.
- Add reducer actions for scene/story beat and scene interaction progress.
- Make GameShell and story scenes controlled by persisted state.
- Add migration/reducer tests.

### Task 2: Rebuild title, prologue, camp and dialogue presentation
- Replace placeholder labels/geometric avatars with reusable illustrated silhouette/portrait components.
- Establish Three-Kingdoms military-camp art direction, scene chrome, ambient motion and responsive layout.

### Task 3: Make document investigation tactile
- Replace answer-highlighted report with selectable report observations.
- Require the player to identify the meaningful observation before recording it.
- Persist the marked observation.

### Task 4: Make handwriting investigation interactive
- Introduce two document samples, magnification/overlay control and multiple feature marks.
- Require two correct observations before applying the investigation rule.
- Persist marked handwriting features.

### Task 5: Differentiate interrogation
- Add evidence dossiers, tactic descriptions, pressure/read feedback and unique response copy per tone.
- Persist attempts and selected tactic/evidence.
- Keep evidence gating tied to collected claims.

### Task 6: Rebuild deduction board interaction
- Make players choose source, target and relationship type before validating.
- Show an animated cinnabar connection on success and useful failure feedback.

### Task 7: Finish slice and verify
- Replace prototype placeholder ending with a v0.6 case-summary scene.
- Run typecheck, unit tests, build, and a smoke test.
- Update README/HANDOFF and package without node_modules/build caches.
