# 《官渡密报》v0.8.2 全局 UI / 交互 / 演出重构方案（审核同步版）

> 基线：Guandu Dispatch v0.7
> 目标：把“古风网页式原型”升级为“军机案牍式三国历史悬疑互动游戏”。

## 1. 核心原则

1. UI 属于世界：按钮、案卷、证据、提示和确认都采用军令、题签、印章、案牍、木牌的视觉语言。
2. 一句话一个镜头：重要人物每次发言都有明确人物卡/分镜，不再只替换文字。
3. 密报属于人物：每份关键文书都显示来源、关联人物、可质证对象和当前任务。
4. 不允许死胡同：全局固定返回 / 案卷 / 当前任务 / 三级提示，并保存完整导航快照。
5. 错误可恢复：场景不匹配时自动修复；无法修复时进入“案卷记录恢复”，不展示开发错误。
6. 音效即反馈：按钮、人物入场、纸张、印章、推理成立、觐见、任务解锁必须有声音反馈。
7. CG 分级：普通对白人物卡；重要对峙双人分镜；粮道夜袭、曹操觐见、关键审讯使用 2.5D CG。

## 2. UI 控件体系

- 主行动：令签式，单屏最多 1–2 个；场景化文案，例如“入帐复命”“呈证质问”。
- 次行动：题签式，查看、询问、打开案卷。
- 工具按钮：返回、案卷、任务、提示、设置，稳定位置。
- 危险按钮：暗朱色，并带二次确认与后果说明。
- 锁定按钮：显示解锁条件，不只置灰。
- 对话选择：竖向签条，语气标签 + 主句，不做现代大圆角按钮。
- 证据：物件化，不用按钮替代纸张、账册、地图。

## 3. 对白和人物卡

建立 Dialogue Presentation System：beat 数据驱动人物、身份、表情、站位、台词、音效、短语音与选择。普通对白每一 beat 切换一张人物卡；重要对峙允许左右双卡交替；曹操觐见使用专用 AudienceScene。

主要人物：曹操、赵简、郑禾、杜衡、陆淳。每人至少具备常态、审视/戒备、强情绪三档表现。

## 4. 导航与存档

导航历史从 `GameSceneId[]` 升级为快照：`sceneId + storySceneId + beatIndex + dialogueNodeId`。旧 v3 存档迁移到 v4 时校验 presentation 合法性；若 `sceneId=dialogue` 但 `storySceneId` 不对应 dialogue，则按案件进度恢复最近合法节点。

## 5. 案卷与任务

案卷七页：人物、密报、证据、推理、任务、教程、设置。默认只显示轻量任务签；展开后提供主目标、当前行动、已完成、下一步。

## 6. 声音

分 UI、纸张/文书、人物入场、环境、关键短语音五层。保留 Web Audio 作为无资源兜底，优先播放静态资源；没有正式语音时只对关键句使用系统语音原型。

## 7. CG

首批四组：粮道夜袭、曹操中军大帐、赵简审讯、军机案桌。采用 16:9/横构图、高暗部、三国写实国风，给对白 UI 留安全区；前端叠加火光、烟尘、镜头推进、轻微视差。

## 8. 阵营与兼容

玩家可见阵营称谓统一为“曹军 / 袁军”，与曹操阶段复命保持世界观一致；存档和规则层继续保留旧 `canghe / shuoyuan` ID，避免破坏旧版本存档。

## 9. 验收

- 刷新 dialogue / audience / interrogation 等核心场景不会出现“场景资料暂不可用”。
- 赵简、郑禾、杜衡、陆淳、曹操均有实际可见人物表现。
- 关键人物对白每句都能看到当前发言者。
- 返回能恢复具体故事节点，不只恢复 sceneId。
- 所有主按钮有层级、按压、hover 和音效。
- 核心操作有声音反馈。
- 项目根目录维护 `UNFINISHED_WORK_REPORT_v0.7.md`，只把玩家真正能使用的内容标成完成。


## 10. v0.8.2 人物 / 历史 / 声音追加规范

- 陆淳、郑禾、杜衡必须使用独立正式人物图，不再回退程序化 SVG；
- 人物身份与案卷用语统一为邮驿主吏 / 军粮书佐 / 军书佐 / 营外行商；
- 案卷必须可查“封检 / 邮书 / 符 / 出入簿 / 车马簿”等制度词汇；
- 重点场景采用差异化浏览器 AI 占位声线，正式配音仍作为后续资产层；
- 夜袭和案桌背景不得再包含明显烘焙的现代 UI 工具栏或对话截图；
- 历史真实地名属于战略背景，首案微观桥路继续架空，保证推理公平。

# v0.8.3 实装补充

## 本地占位配音优先级
重点剧情采用：`本地 TTS WAV → 浏览器中文 TTS → 静默`。本地资源保证曹操复命、赵简突破和三名支线人物关键承认在试玩机器上有统一声音基线；普通非关键句不强求逐句配音。

## 人物案卷正式立绘
人物页不再以姓名首字作为主要视觉。曹操、赵简、陆淳、郑禾、杜衡的正式人物图与疑点、责任、任务、关联文书并列。人物图服务案件导航，不做纯收藏图鉴。

## 历史制度可读性
新增封检题署、以邮行、以次行 / 以亭行、驰行、轻足行、传马 / 传车等术语，但只在它们能够解释“谁经手、何时交接、为何能加急、谁有权限”时进入玩法；禁止把术语堆砌本身当作历史感。
