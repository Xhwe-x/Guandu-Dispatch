# 一、结论摘要

当前 v0.8.1 已经形成一条可从标题完整玩到政治结局的案件链，并把 v0.3 的“碎片情报 → 多渠道拼合 → 主动投饵 → 敌军回声 → 最终汇报”保留为核心。v0.8.1 的主要价值是把原本偏网页原型的表现层重构为军机案牍式 UI，并补上人物卡、曹操复命、完整导航快照、异常恢复、本地操作音效与四组关键 CG。

但当前版本仍不能被描述为“Steam 商业美术最终版”。最主要缺口是：陆淳 / 郑禾 / 杜衡最终立绘、正式角色配音、完整 2.5D 分层演出、真人无指导试玩，以及目标平台 production build / Vitest / Oxlint 的最终验证。

# 三、第 2 轮审核：完整玩法链与“死胡同”

已经建立 DOM 级完整通关脚本，实际依次点击：

```text

→ 敌军回声
→ 第二次觐见曹操
→ 最终报告
→ 真相归属
→ 结局
```

全局案件导航已经包含：

- 返回；
- 案卷；
- 当前任务；
- 三级提示。

返回不再只保存 `sceneId`，而保存完整导航快照：

```text
sceneId + storySceneId + beatIndex + dialogueNodeId
```

旧 v3 存档进入 v4 时会校验演出位置；`dialogue` 与 `storySceneId` 错位时会自动恢复最近合法节点。无法自动恢复时显示“案卷记录恢复”，不会再显示“场景资料暂不可用”“dialogue”等开发信息。

## 部分完成

- 当前已有“安全返回”和完整快照，但仍需要真人试玩验证所有非主路径操作组合（例如在某些案卷/提示打开状态下多次返回）是否符合直觉；
- 目前主要验证覆盖主通关链，不等于穷举所有错误操作路径。

## 审核判断

**核心死胡同问题已修复；边缘交互仍需真人探索测试。**

# 四、第 3 轮审核：UI 控件、按钮与信息架构

## 已完成

### 通用控件

- `GameButton`：主行动、次行动、危险、静默等层级；
- `GameIconButton`：返回 / 案卷 / 任务 / 提示；
- `ChoiceStrip`：曹操复命与重要选项的签条式选择；
- 主行动不再依赖默认现代圆角按钮；
- hover / focus / pressed / disabled 有独立反馈；
- 锁定行动可以显示原因；
- 主按钮使用场景化文案，例如“入帐觐见”“呈证质问”“封印并呈交”。

### 案卷

案卷已经变为七页书签：

- 人物；
- 密报；
- 证据；
- 推理；
- 任务；
- 教程；
- 设置。

### 世界内物件控件

证据、投饵、推理、最终报告等仍需要多选按钮，但已经统一为纸张 / 题签 / 案牍材质，不再使用浏览器默认按钮外观。

## 部分完成

- 项目仍保留少量旧 `.scene-button` 样式与少数旧组件，用于兼容非核心/旧原型区域；核心主流程主要行动已迁移到 v0.8 控件；
- 证据 chip、报告选择、投饵选项等仍属于“按钮语义的可操作物件”，虽然视觉已经重做，但后续仍可进一步加强真实拖拽、拿取和落案动画；
- 设置页的 range 滑杆仍是 Web 控件基础上进行视觉适配，尚未做完整铜制刻度式自定义控件。

## 审核判断

**主流程按钮与导航完成度明显提升；“所有可操作物件完全去按钮化”尚未完成，也不建议为了形式强行全部去按钮。**

# 六、第 5 轮审核：音效、语音与 CG

## 已完成

### 本地音效

当前已经提供本地 WAV：

- UI 点击；
- 重要确认；
- 返回；
- 案卷书签；
- 展开纸张；
- 收起纸张；
- 落印；
- 入帐；
- 人物入场；
- 证据落案；
- 推理连线；
- 警告；
- 任务解锁。

声音资源加载失败时保留 Web Audio 兜底，不会因为缺少单个 WAV 导致按钮失效。

### 关键语音原型

曹操 / 查案官的关键短句已预留并实际触发 SpeechSynthesis，例如：

- “参见主公”；
- “起身，坐前回话”；
- “孤要真相”；
- “臣领命”。

### CG

当前已经实际接入：

1. 粮道夜袭；
2. 曹操中军大帐；
3. 赵简审讯；
4. 军机案桌。

场景通过 CSS 光影、遮罩、人物卡、UI 层叠等方式强化镜头感。

## 部分完成

- CG 当前主要是整张关键画面 + 前端叠层，不是所有画面都拆成前景 / 人物 / 烟尘 / 火光 / 后景独立图层；
- 环境声音还没有形成完整持续循环混音，例如整场持续营帐风声、火焰、远鼓、马匹等；
- SpeechSynthesis 受操作系统语音库影响，不能作为正式声音品质标准。

## 未完成

- 真人角色配音或最终批准的高质量 TTS 音频文件；
- 全角色统一声线表；
- 正式 BGM 与环境氛围混音；
- 四组 CG 的完整 2.5D 拆层和独立局部动画。

## 审核判断

**声音已经从“无反馈”进入可用原型层；正式音频与完整 2.5D 是明确未完成项。**
