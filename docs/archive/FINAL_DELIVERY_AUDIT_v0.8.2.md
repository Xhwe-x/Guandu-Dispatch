## 二、部分完成

- AI 占位语音仍依赖用户操作系统 / 浏览器提供的中文 SpeechSynthesis voice，不同机器实际音色会有差异；
- 人物图目前每人主要是 1 张正式基础图，情绪变化仍大量依靠亮度、构图和 UI 状态；
- 夜袭和案桌 CG 已清掉明显 UI 拼贴，但图像本身仍来自原有 AI 概念资产，并非最终商业级绘制；
- 历史制度采用“史实词汇 + 游戏化合并”，不是逐条复刻某一份汉简公文格式。

- 当前容器内 Vitest / Vite production build / Oxlint 最终通过证明。

## 四、当前环境未验证项

本轮尝试 `npm ci --ignore-scripts --no-audit --no-fund`，70 秒后超时并留下不完整 `node_modules`。随后 `npx tsc -b` 明确报缺少 `vite/client` 和 `node` 类型，`verify:v08` 也因不完整安装缺少 zod 运行时而停止。

因此这些失败归类为**依赖安装环境未完成**，不能写成代码通过，也不能写成代码失败。最终包会删除这份不完整 `node_modules`。

## 五、需要用户支持

1. **试玩反馈**：下一次试玩重点记录“人物是否一眼能区分、哪段语音最出戏、哪个控件仍像网页、哪里仍不知下一步”；
2. **正式配音方向**：若占位声线节奏满意，再决定是否使用外部 TTS 生成固定音频文件，或寻找真人配音；
3. **历史化强度**：若希望进一步考据，可继续决定是否让地图出现更多真实节点（延津 / 乌巢等），还是保持当前“真实战略背景 + 架空微观路线”；
4. **目标机验证**：在正常联网 Windows/macOS/Linux 环境执行 `npm ci && npm run test:run && npm run build && npm run lint`，把任何报错截图发回。

## 六、结论

v0.8.2 已把本轮确认的三项方向真正落到游戏：**三名人物正式图、历史化制度与文书、差异化 AI 占位半配音**。下一阶段最有价值的工作不再是继续大量加系统，而是补人物情绪变体、固定配音资产和真人试玩后的定向调整。
