# 《官渡密报》v0.8.3 增量审核记录

> 日期：2026-08-27  
> 基线：v0.8.2 可通关版本  
> 本轮目标：继续提高人物资源利用率、占位配音可靠性与汉代邮传制度表达。

## 1. 本轮完成

### 本地占位配音
- 新增 `public/assets/voice/`，包含曹操、查案官、赵简、陆淳、郑禾、杜衡的重点对白 WAV；
- `GameAudio` 改为：**本地对白 WAV → 浏览器中文 SpeechSynthesis → 静默** 的分级策略；
- `stopVoice()` 会同步停止本地语音和浏览器语音，避免切镜后上句仍在播放；
- 曹操“起身”“陈明所查”“孤要真相”“最终军令”，赵简突破，以及三名支线人物关键承认均有固定占位资源。

> 说明：这些 WAV 为当前环境可生成的 TTS 占位音，不代表最终商用配音。它们的价值是保证试玩时重点剧情在不同浏览器上都有声音基线。

### 人物案卷
- 曹操、赵简、陆淳、郑禾、杜衡正式人物图现在直接进入案卷“人物”页；
- 不再只显示姓名首字和文本；
- 人物图与疑点、责任边界、关联文书、下一步任务并置，强化“人物—证据—任务”关系。

### 历史化继续深化
- “封检”说明扩展到封检题署：收件者、传递方式、封缄类别与交接信息；
- 新增邮传方式速查：以邮行、以次行 / 以亭行、驰行、轻足行、传马 / 传车；
- 官渡地理说明明确“官渡与延津”为战略背景，“乌巢”为后续粮秣压力背景；
- 首案具体邮置、北桥、商路与伏击点继续架空，以保证谜题公平，不让玩家靠背历史地图解题。

## 2. 仍属于占位/部分完成
- 本地 TTS 音频仍是占位，不是最终 AI 商用声线或真人配音；
- 陆淳、郑禾、杜衡仍以一张基础正式图配合镜头、亮度和状态标签变化，没有 3–5 张独立表情变体；
- 历史称谓采用“史实制度词汇 + 游戏化职名”，不宣称每个架空角色职名都能与某一枚汉简逐字对应；
- 2.5D CG 仍未完成逐层人物/烟尘/前景拆分。

## 3. 下一轮试玩最值得观察
1. 曹操本地占位配音是否太机械、太慢或太长；
2. 三名新人物进入案卷后是否一眼能区分身份；
3. “封检 / 邮书 / 驰行”等术语是否帮助沉浸，还是增加理解负担；
4. 人物页右侧立绘是否遮挡信息；
5. 四匣并查中人物切换是否仍像网页分页。

## 4. 状态清单

### 已完成
- 本地重点对白 WAV 与浏览器语音回退链；
- 曹操 / 赵简 / 陆淳 / 郑禾 / 杜衡人物图进入案卷；
- 封检题署与邮传方式教程；
- 官渡 / 延津 / 乌巢战略背景说明；
- v0.8.3 对应结构审核脚本。

### 部分完成
- 重点场景半配音：核心句已覆盖，但并非逐句配音；
- 人物情绪表现：仍以单张正式图 + 镜头 / 明暗 / 状态标签为主；
- 历史化：制度词汇进一步真实化，但架空角色职名仍为游戏化组合；
- CG：已清理 UI 拼贴，但尚未全部拆成真正 2.5D 层。

### 未完成
- 三名支线人物 3–5 张独立表情变体；
- 可商用的最终 AI 声线或真人配音；
- 全重点场景逐句语音；
- 全量 2.5D 前 / 中 / 后景拆层；
- 真人无引导试玩验收。

### 需要用户支持
- 下一轮试玩时记录：声音是否太机械、人物是否一眼可辨、历史术语是否难懂、案卷是否遮挡、四匣切换是否仍像网页；
- 若决定正式配音，需要确定最终声线供应方式与授权范围；
- 若希望进一步历史化，需要决定真实地名在谜题层出现的上限，避免“考据答案”替代推理答案。
