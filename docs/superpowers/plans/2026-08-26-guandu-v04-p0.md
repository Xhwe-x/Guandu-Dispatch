# 《官渡密报》v0.4 P0 体验升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有三栏推理原型升级为第一次打开就会玩的入口、开场和赵简第一条可玩证据链，并建立可持续的军帐案桌视觉基础。

**Architecture:** 保留现有规则与 `Stage`，把教学作为可迁移的 `TutorialState` 叠加在 `GameState` 上。`ExperienceRouter` 只负责体验状态，`TutorialController` 只从真实案件状态推导目标；文书、调查、审讯和关系板继续调用现有 reducer/rule。视觉 token 与功能组件分离，资源缺失时安全降级。

**Tech Stack:** React 19、TypeScript、Vite、Vitest、React Testing Library、Playwright、Zod。

**Spec:** `docs/superpowers/specs/2026-08-26-guandu-v04-p0-design.md`；细化路径见 `docs/superpowers/specs/2026-08-25-guandu-onboarding-design.md`。

## Global Constraints

- 不改变既有确定性推理规则、关系白名单和 `Stage` 顺序。
- 新游戏版本为 v2，教学默认 `notStarted`；v1 存档迁移为 `skipped`。
- 跳过引导不得赠送证据、扣调查点、增加关系或推进阶段。
- 第一条教学主张使用 `claim-shuoyuan-received`；不得提前提取 `claim-ambush-north`。
- 赵简教学必须使用真实笔迹调查、真实审讯和 `claim-zhao-copied-order → refutes → claim-zhao-denial / leakedInfo`。
- 不新增服务器、账号、随机、倒计时或未经授权的二进制素材。
- 每个任务按 RED → GREEN → 全量 test/build/lint → 独立提交 → 独立审查执行。
