# Guandu Dispatch v0.9 Reset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reset v0.8.3 into the v0.9 narrative/UI baseline: restrained component system, responsive scene layouts, and a gradual onboarding flow from background to first deduction before interrogation.

**Architecture:** Preserve the existing case rules, evidence graph, persistence, and later-game logic. Replace the presentation layer with a token-driven `src/ui` component system and add a data-driven guided opening sequence; route existing document/dialogue/deduction/interrogation mechanics through this sequence rather than exposing advanced systems immediately.

**Tech Stack:** React 19, TypeScript, Vite, CSS, existing local audio/CG assets.

**Spec:** `/mnt/data/官渡密报_v0.9_叙事流程与UI组件系统重构方案.md`

## Global Constraints

- v0.9 overrides earlier UI/flow guidance when requirements conflict.
- Baseline viewport: 1920×1080; minimum supported viewport: 1366×768 without horizontal scroll or clipped scene titles.
- Ordinary scene titles: 22–28px; dialogue/body: 16–18px; top navigation: 13–15px.
- Top scene navigation height: 48–56px.
- One primary visual center per scene; at most two primary actions visible at once.
- Page-level components may not reimplement buttons/cards/modals locally once primitives exist.
- First-time flow: background → identity → three-item onboarding → Zhao introduction → first statement → document comparison → guided first deduction → second Zhao conversation/interrogation.
- CG is reserved for sequence transitions, first character reveals, major breakthroughs, Cao Cao audiences, bait, enemy response, and endings.
